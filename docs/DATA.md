# Data contract

For each split `train`, `val`, `test`:

- `<split>.npy`: (N, 22, 2000), EEG in microvolts after bipolar montage/filtering.
- `<split>_multi_label.npy`: (N,), integer 0=CFSZ, 1=GNSZ, 2=ABSZ, 3=CTSZ.
- `<split>_bi_label.npy`: (N,22), channel-wise binary labels.
- `window_manifest_array_order.csv`: split, array_index, event_id, class_id,
  patient_id; fresh preprocessing includes recording and window timing fields.

FNSZ/SPSZ/CPSZ map to CFSZ; TNSZ/TCSZ map to CTSZ. Unsupported, generic-only,
and conflicting event classes are excluded. Channel targets mark any supported
ictal annotation overlapping the window on that bipolar channel.

The builder refuses a nonempty output directory unless explicitly overridden;
use a new directory. It stops if processing drops any planned window, rather
than silently compacting arrays and leaving an incorrect manifest. Audit checks
row coverage, class agreement, event class consistency, patient/event split
intersections, array shapes, label range, and finite values.

Synthetic fixtures are generated by `make_smoke_data.py`. Raw synthetic EDFs
for the preprocessing integration test are generated temporarily by the tests.
The fixtures contain no patient data.

The assignment CSV includes patients assigned before window retention (196/22/18 for train/validation/test). These are not retained-sample counts. In the main 10-second run, eligible training events involve 169 patients and 1,413 events; retained windows involve 167 patients and 1,401 events. Some events contribute no valid windows. The final validation/test windows involve 21/16 patients. Per-epoch training sampling targets are 8,000/4,000/800/800 for CFSZ/GNSZ/ABSZ/CTSZ.
